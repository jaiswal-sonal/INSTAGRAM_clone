# Instagram Clone (Express + EJS + MongoDB)

## Chalane ke steps
1. Node.js (v16+) aur MongoDB install karo, aur **MongoDB chalu karo** (`mongod` ya MongoDB Compass / service).
2. Project folder mein:
   ```
   npm install
   npm start
   ```
3. Browser mein kholo: http://localhost:3000

Atlas ya alag Mongo URL use karna ho to:
`MONGO_URL="mongodb+srv://..." npm start`
